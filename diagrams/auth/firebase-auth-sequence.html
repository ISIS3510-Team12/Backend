Firebase authentication and application-user flows

Kotlin and Flutter clients send Firebase ID tokens to FastAPI. The backend resolves the corresponding application user for protected endpoints or creates a new application profile.

Resolve the current application user

Protected endpoints declare CurrentUser when they require an application profile. After FirebaseUser verifies the bearer token, get_current_user() looks up the Firebase uid as the User primary key and rejects missing profiles with HTTP 403.

Current-user dependency mapping

C0Kotlin Firebase.auth.currentUser?.getIdToken(false)
C0Flutter FirebaseAuth.instance.currentUser!.getIdToken()
C1Endpoint GET /auth/current_user · current_user: CurrentUser
C2Dependency CurrentUser = Annotated[User, Depends(get_current_user)]
C3Backend get_current_user(firebase_user: FirebaseUser, db: DatabaseSession) -> User
C3Lookup db.get(User, firebase_user["uid"])
C4Database Return User or None
C5Found return user
C6Endpoint Run endpoint logic with the injected User
C7Missing raise HTTPException(status_code=403, detail="Application user does not exist")
C8Response HTTP 403

Create the application user

POST /auth/create_user creates the application profile for an authenticated Firebase identity. The endpoint validates the submitted profile, rejects an existing uid, records the Firebase sign-in provider, commits the new User, and returns it with HTTP 201.

Create-user endpoint mapping

S0Kotlin Firebase.auth.currentUser?.getIdToken(false)
S0Flutter FirebaseAuth.instance.currentUser!.getIdToken()
S1Request POST /auth/create_user · Bearer ID token + UserCreateRequest
S2Dependency firebase_user: FirebaseUser · request: UserCreateRequest · db: DatabaseSession
S3Endpoint uid = firebase_user.get("uid"); db.get(User, uid)
S4Database Return an existing User or None
S5Existing uid raise HTTPException(status_code=409, detail="User already exists")
S6Response HTTP 409 Conflict
S7New uid _get_auth_provider(firebase_user); db.add(user); db.commit(); db.refresh(user)
S8Database Return the persisted User
S9Endpoint return user
S10Response HTTP 201 Created · User
GUARDMissing uid HTTP 422 · missing or invalid Firebase uid
COMMITIntegrityError db.rollback(); HTTP 409 Conflict
